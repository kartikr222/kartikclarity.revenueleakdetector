# Kartik Clarity™ Revenue Leak Diagnosis

A premium AI-powered web application that analyzes business metrics to identify revenue leaks and provide actionable recommendations.

## Tech Stack
- **Frontend:** React + Vite + TypeScript + Tailwind CSS + shadcn/ui
- **Backend:** Supabase (PostgreSQL + Edge Functions)
- **AI:** Google Gemini 2.0 Flash API
- **Hosting:** Vercel (frontend) + Supabase (backend)

## Features
- AI-powered revenue leak detection
- Comprehensive business metrics analysis
- Revenue Leak Score (0-100)
- Detailed leak categories with impact analysis
- Actionable recommendations
- Premium design (Stripe/Linear inspired)

## Local Development
1. Clone the repository
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and fill in your Supabase credentials
4. Run development server: `npm run dev`

## Deployment
- Frontend: Vercel
- Backend: Supabase
- Live URL: https://revenue-leak-diagnosis.vercel.app
